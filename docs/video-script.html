Deck: cover, then the problem slide

Enterprises are connecting AI analyst agents to governed data. Zetaris enforces masking and access at the data layer. But the agent sits above it: it reads untrusted text, holds tools and keeps memory. Gauntlet is for the platform lead who has to certify that agent before it touches enterprise data, and again after every change.

Zetaris is the data layer. Nightshift and Nemotron run every call. World Model records every trace, and H-MEM holds the agent’s memory and the exploit corpus, both with passing conformance suites. Instructions don’t enforce. Code does. Every number reproduces from the public repo with no credentials: github.com/yazzer5/gauntlet.

If something breaks while recording

  • Explain is slow or errors: click it again, or cut it and say the same line over the v2 replay instead. The replay is also a live Nightshift request.
  • Replay errors (Lightning 502): just press it again; it falls back to Bolt.
  • Zetaris or Nightshift won’t start: set SAMPLE_MODE=true and restart. Everything works except Explain. Skip that beat and say “recorded from live Nemotron runs”.
  • Don’t click Replay every exploit on v2 on camera. It runs 12+ live sessions and takes minutes.
